# 可露希尔 ClosureMod

这是一个《Slay the Spire 2》的可露希尔角色 Mod。可露希尔围绕费用管理、债务、迟钝、眩晕和无人机模块构筑牌组，并加入了专属遗物、衍生牌、先古牌和事件「罗德岛工作间」。

本项目当前是可游玩的开发版本，内容仍会继续调整。仓库中的 `src/ClosureMod` 是正式 Mod 工程；已经处理好的卡面、角色模型、遗物、能力、事件和本地化文件都随工程维护。

## 当前状态

- Mod 名称：`可露希尔`
- Mod ID：`ClosureMod`
- 作者：`火山温泉浴`

- 依赖：`STS2-RitsuLib 0.5.20`
- 当前工程版本：`0.0.0`（开发版版本号）
- 角色模型：战斗中使用 `idle`、攻击 `attack_begin / attack_loop / attack_end`、死亡 `die` 动画。
- 非战斗角色：酒馆、火堆等场景通过补丁尝试使用角色 `idle` 模型。
- 本地化：中文（简体）和英文资源均已保留。

## 核心机制

### 迟钝与眩晕

迟钝是可露希尔的核心状态。它会降低由迟钝影响到的攻击伤害；达到角色的触发阈值后，会触发本回合眩晕，并清理对应的迟钝。部分牌会直接给予迟钝、翻倍迟钝、降低触发阈值，或根据敌人的迟钝层数计算伤害和格挡。

敌人的「沙坑」和「沉睡」属于不会被迟钝随机衰减的特殊状态。角色牌文案中出现“下回合进入眩晕”时，效果会在下回合开始时结算；普通的迟钝触发仍按战斗中的迟钝机制处理。

### 费用、负能量与债务

可露希尔可以通过初始遗物把能量降低到负数。回合结束时，负能量会转化为债务层数。债务可以被部分牌和能力利用，也可以通过清空能量、赚取费用或其他费用牌来管理。

费用图标、债务关键字和卡牌描述使用游戏本体的本地化格式。仓库中保留了债务相关代码，但只有明确带有债务效果的牌会显示债务文案。

### 无人机模块

可露希尔的模块牌会召唤攻击、防御或后援模块。模块拥有自己的生命值和能力，相关衍生牌「等我启动」和「我已启动」会清空或使用场上的模块资源。

### X 牌与抽卡

`抽卡` 是 X 费攻击牌。它从符合条件的 X 费牌中随机提供 3 张选择，使用与原版无色卡「发现」相近的大型选牌界面。选中的牌会自动对当前目标打出，并获得本次结算后捕获的 X 值；该牌不会被加入普通牌堆，下一次使用后会被消耗。

候选牌池按已注册卡牌模型筛选，兼容其他 Mod 注册的 X 费牌；状态牌、诅咒牌和 `抽卡` 自身不会进入候选池。升级后额外触发 1 次，绿色升级数字由游戏本体的升级文本样式显示。

## 事件：罗德岛工作间

使用可露希尔时，首次进入问号房会遇到「罗德岛工作间」。事件使用专属背景图，并包含两个阶段：

1. **初始页面**：
   - **进去看看**：花费 42 金币，进入工作间。
   - **离开**：获得 42 金币并结束事件。
2. **工作间**：选择左侧抽屉「可露希尔的收藏」，或右侧抽屉「好友的馈赠」。
3. **可露希尔的收藏**：选择高卢支票或礼品卡，点击选项即可直接获得遗物。
4. **好友的馈赠**：选择结构性原理或狙击镜，点击选项即可直接获得遗物。

事件遗物只通过该事件获得，不进入商店普通遗物池。事件文本中的折扣、特殊价格、护盾和伤害累积说明是玩法效果；礼品卡图鉴只显示简洁描述“商店商品更容易打折”。

## 安装

1. 准备《Slay the Spire 2》的 Mod 加载环境。
2. 安装并启用依赖 Mod：`STS2-RitsuLib`，版本至少为 `0.5.20`。
3. 打开游戏目录下的 `mods` 文件夹。Steam 默认路径通常类似：

```text
C:\Program Files (x86)\Steam\steamapps\common\Slay the Spire 2\mods
```

4. 将发布压缩包解压到 `mods` 目录，使目录结构类似：

```text
Slay the Spire 2\mods\ClosureMod\ClosureMod.json
Slay the Spire 2\mods\ClosureMod\ClosureMod.dll
Slay the Spire 2\mods\ClosureMod\ClosureMod.pck
```

5. 启动游戏，在 Mod 列表中确认 `可露希尔` 已启用。

如果压缩包解压后出现 `mods\ClosureMod\ClosureMod\ClosureMod.json`，说明多套了一层目录，需要把里面那层 `ClosureMod` 提升到 `mods` 下。

工程文件位于 `src/ClosureMod`。构建需要 .NET SDK、Godot/MegaDot 导出环境，以及本地可用的 `STS2-RitsuLib` 依赖。

仅编译 DLL：

```powershell
$env:NUGET_PACKAGES = 'C:\Users\Administrator\.nuget\packages'
dotnet build src/ClosureMod/ClosureMod.csproj -c Release --no-restore -p:CopyModOnBuild=true -p:RunPckExport=false
```

导出 PCK：

```powershell
$env:APPDATA = 'D:\SlayTheSpire2Mod\.godot\appdata'
& .\tools\Godot_v4.5.1-stable_mono_win64\Godot_v4.5.1-stable_mono_win64_console.exe `
  --headless `
  --path .\src\ClosureMod `
  --export-pack 'Windows Desktop' `
  'D:\steam\steamapps\common\Slay the Spire 2\mods\ClosureMod\ClosureMod.pck'
```

完整构建会把 DLL 和 PCK 复制到游戏的 `mods\ClosureMod` 目录。构建缓存、Godot 导入缓存、本机路径配置、原始卡面、临时素材和调试工具不会提交到仓库；正式资源应放在 `src/ClosureMod/ClosureMod` 下并由工程引用。

## 项目结构

```text
src/ClosureMod/
  ClosureMod/                 # Mod manifest、本地化、场景和已处理资源
  ClosureModCode/             # 卡牌、遗物、能力、事件和 Harmony 补丁
  ClosureMod.csproj           # C# 工程
  ClosureMod.json             # Mod 元数据和依赖
```

主要代码区域：

- `ClosureModCode/Cards`：卡牌、X 牌和衍生牌。
- `ClosureModCode/Powers`：迟钝、债务、无人机和费用相关能力。
- `ClosureModCode/Relics`：初始遗物、先古遗物和事件遗物。
- `ClosureModCode/Events`：罗德岛工作间事件。
- `ClosureModCode/Patches`：卡牌选牌、迟钝、金币显示、角色模型等兼容补丁。
- `ClosureMod/images`、`models`、`scenes`、`localization`：游戏实际加载的资源。

## 版本与反馈

这是开发中的 Mod。若游戏更新后出现卡牌显示异常、模型不加载、事件黑屏或与其他 Mod 冲突，请同时提供：游戏版本、Mod 列表、复现步骤和日志中的报错位置。提交前请确认修改已经写入 `src/ClosureMod`，不要直接把本地 `new card`、`gift`、调试脚本或 Godot 缓存复制进发布包。
