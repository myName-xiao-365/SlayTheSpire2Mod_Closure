# 可露希尔（ClosureMod）

《杀戮尖塔 2》可露希尔角色模组。工程、无人机、迟钝和费用调度是主要玩法。本仓库只维护可露希尔自己的角色内容：卡牌、能力、罗德岛工作间事件、遗物、角色立绘与动画。支援牌和公共状态效果由独立前置 [ArkBase](https://github.com/myName-xiao-365/ARK-base) 提供。

## 前置与安装

必须同时安装 `ArkBase`（清单要求 0.1.0）和与当前游戏版本匹配的 `STS2-RitsuLib`（清单要求 0.5.20）。`ClosureMod-版本号.zip` 中包含 `ClosureMod` 文件夹；将三个模组文件夹分别放在游戏的 `mods` 目录，不要合并。游戏会先加载前置，再加载本模组。

本项目不会复制或捆绑 `ArkBase.dll`。可露希尔的“大家”“支援打击”“随机直升”等卡牌调用 ArkBase 的公共支援牌；“等我启动”“我已启动”“订单”仍由本模组自己定义。

## 内容

- 可露希尔角色、初始卡牌和遗物、动画与专属界面资源。
- 迟钝、费用、支援牌和无人机相关的角色卡牌与能力。
- “罗德岛工作间”事件，以及高卢支票、礼品卡、结构性原理、狙击镜等事件遗物。
- 中英文文本与对应插图。

“平局”“奇怪的按钮”及只由平局产生的“创伤”已删除，不再作为彩蛋。

## 事件：罗德岛工作间

使用可露希尔时，本次冒险第一个问号房必定出现此事件。事件使用专属背景图，遗物只通过本事件获得。

### 初始

沿着罗德岛舰内的维修通道前行，你在一处岔路旁发现了一扇虚掩着的门。门上的铭牌已经被各种贴纸盖得七七八八，只勉强能看见原本的几个字：

「罗德岛工程部」

工作台上的终端还亮着，拆了一半的设备散落得到处都是。线缆、扳手、零件盒和叫不出名字的电子元件几乎占满了所有可以放东西的地方。

- **进去看看**：花费 42 金币，进入工作间。
- **离开**：获得 42 金币，离开。离开时，你注意到工作台下几个没有上锁的抽屉，最终还是转身离去：“……还是不要乱翻别人的东西了。”

### 工作间

越往里走，工作间就显得越不像一个单纯用来维修设备的地方。架子上摆着许多早已停产的零件，墙角堆着来源不明的设备外壳，几个纸箱上甚至还贴着年代久远的运输标签。在工作台下方，有两个抽屉没有完全合上。

- **翻翻左边的抽屉**：查看可露希尔的收藏。
- **翻翻右边的抽屉**：查看好友的馈赠。

### 可露希尔的收藏

抽屉里塞着不少稀奇古怪的东西，有些看起来价值不菲，有些则早已失去了原本的用途。有两件东西格外醒目，一本装饰得夸张到近乎俗气的旧支票本以及一张被保存得异常完好的礼品卡。

- **拿走「高卢支票」**：金币最低可降低至 -100。
- **拿走「礼品卡」**：商店商品更容易打折。

### 好友的馈赠

这个抽屉明显比另一边整齐得多。柔软的衬垫上只放着两件东西，一只小小的机械长颈鹿，以及一枚被仔细擦拭过的狙击镜。它们看起来都被使用过很长时间，但都被保存得很好。

- **拿走「结构性原理」**：每场战斗仅一次，护盾可格挡超额伤害。
- **拿走「狙击镜」**：每回合开始，本场战斗造成的伤害提高 10%。

选取任一遗物后，遗物立即加入并结束事件。终端会记录库存变动，并留下“下次记得先问价”的提醒。礼品卡描述只写“商店商品更容易打折”；具体折扣概率不展示在事件或遗物文案中。

## 本地构建

需要 .NET 9 SDK、Godot 4.5.1 Mono、游戏本体、RitsuLib 兼容包，以及**已安装的 ArkBase**。将 `local.props.template` 复制为 `local.props`，填写游戏和 Godot 路径；若 ArkBase 的 DLL 不在游戏 `mods\ArkBase`，另外设置 `ArkBaseDll`。`local.props` 不会提交到仓库。

```powershell
& .\build.ps1
```

脚本仅从本仓库读取源码，从已安装的 ArkBase 读取编译依赖，输出 `dist\ClosureMod-版本号.zip`，默认也会安装到游戏。`-NoInstall` 只生成发布包；`-GameDir`、`-GodotExe` 可覆盖本机配置。**不需要**把两个仓库放在相邻目录。
